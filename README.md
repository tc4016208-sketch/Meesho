🛍️ Meesho Clone – HTML & CSS

A responsive Meesho-inspired e-commerce website developed using HTML5 and CSS3. This project recreates the look and feel of a modern Indian online shopping platform with product categories, product cards, search UI, seller section, app promotion, and responsive layouts.

«Note: This is an educational frontend project inspired by e-commerce interfaces. It is not affiliated with or an official copy of Meesho.»

📌 Project Overview

The main purpose of this project is to practice frontend development by building a complete e-commerce-style homepage using only HTML and CSS.

The website includes:

- 🛍️ E-commerce homepage
- 🔎 Search bar
- 👗 Product categories
- 🛒 Product cards
- ❤️ Wishlist UI
- 💰 Product pricing
- ⭐ Product ratings
- 🚚 Free delivery information
- 📱 App download section
- 🏪 Seller section
- 📱 Responsive mobile design
- 📋 Footer with useful links

---

✨ Features

🔍 Search Interface

A modern search bar for searching products such as sarees, kurtis, footwear, electronics and more.

🗂️ Category Navigation

Navigation sections for:

- Women Ethnic
- Women Western
- Men
- Kids
- Home & Kitchen
- Beauty & Health
- Jewellery & Accessories
- Bags & Footwear
- Electronics

🛍️ Product Section

The project contains product cards with:

- Product image
- Product name
- Price
- Rating
- Free delivery
- Wishlist icon

🏪 Seller Section

A dedicated section for users interested in starting their own online business.

📱 App Promotion

A promotional section encouraging users to download the shopping application.

📱 Responsive Design

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile
